---
description: 对截图、URL 或本地页面做七维 rubric UI 评审，输出评分报告与结构化修改指令
argument-hint: [截图路径或 URL]
---

你是资深 UI 评审员。对以下目标做**只读评审**（不实现、不修改）：$ARGUMENTS

若目标含 URL 或本地地址，先用浏览器能力打开并按状态矩阵截图（≥2 断点 × 默认/交互态）；若为截图路径，直接 Read 查看。

按以下七维逐项评分（0-5），每一维必须引用具体视觉证据，<3 分项给出结构化修改指令（区域/选择器 + 期望）：

1. **视觉层次**——3 秒能否读出页面用途与下一步
2. **间距对齐**——是否 8pt 刻度、有无光学对齐
3. **配色克制**——强调色 ≤1？有无渐变/裸黑白？对比度达标？
4. **字体阶梯**——层级是否字号+字重双重区分
5. **状态完整**——loading/empty/error/success 四态
6. **交互反馈**——hover/focus/disabled/操作反馈
7. **一致性**——同类元素规范统一、气质连贯

输出格式：七维评分表（分数+证据+修改指令）→ 总分与结论 → 修改优先级排序的 issue 清单。评审与实现分离：只输出报告，不做任何修改。用户确认后再进入修复。

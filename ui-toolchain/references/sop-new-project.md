# SOP-A：从零构造（新项目 UI）

1. **令牌先行**：定稿 design tokens（间距刻度/字号阶梯/一强调色/语义色）写入项目令牌文件；实现者只准消费变量，禁止自造色值。
2. **组件约束**：有 registry（shadcn 等）则组件一律取自 registry；无则按规约自建并保持单一原语源。
3. **生成**：注入规约 + frontend-design skill 后生成；结构对齐选定布局形态（工作台=高密度侧栏，浏览型=卡片流，见变体选择法）。
4. **观测**：状态矩阵截图（≥2 断点 × 默认/交互态），存 `shots/<页>/vN/`。
5. **评审**：七维 rubric 独立评分（用 /ui-review 或 ui-reviewer 子代理），先出报告再改码。
6. **修复**：评审报告作为结构化 issue 回注；改完同参数复拍。
7. **沉淀**：反复出现的问题回写负面清单。

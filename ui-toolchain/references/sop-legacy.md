# SOP-B：存量系统改造

1. **先门禁后改造**：改造前建立基线——全页截图（多断点）+ 确定性审计（用 checklist-design 的 audit 模式逐清单项出核查表）+ 硬编码样式扫描（色值/间距/字号统计）。
2. **三步渐进（strangler，每步可独立上线）**：
   - ① 止血：CSS 覆盖层修字体/对比度/focus/alert 假交互，**不动结构**；
   - ② token 化：硬编码色收敛为 CSS 变量/令牌文件，定宽改响应式；
   - ③ 渐进替换：按页接入新 shell 与组件，新旧路由共存，替换一页下线一页。
3. **每步复拍对照**，视觉回归防"改 A 坏 B"。
4. **分支**：现代框架 → 组件替换；服务端模板 → 只做①②+模板片段替换；原生/canvas GUI → 见 gui-recipes.md 观测通道决策表（截图通道可能结构性失效，需换无头快照/人眼 oracle）。
